# Инструкция по настройке насыщенности темы

## Использование скрипта

Скрипт `adjust_saturation.py` позволяет регулировать насыщенность цветов в теме без изменения серых тонов.

### Быстрый старт

```bash
# Уменьшить насыщенность до 70% от оригинала
python adjust_saturation.py 0.7

# Уменьшить насыщенность до 50% (более тусклые цвета)
python adjust_saturation.py 0.5

# Вернуть к оригиналу (100% насыщенности)
python adjust_saturation.py 1.0
```

### Параметр насыщенности

- **1.0** — оригинальная насыщенность (без изменений)
- **0.8** — слегка приглушенные цвета (рекомендуется)
- **0.6** — умеренно приглушенные цвета
- **0.4** — сильно приглушенные цвета
- **0.1** — минимальная насыщенность

### Что происходит

1. При первом запуске создается резервная копия: `themes/Danast-Night.backup.json`
2. Скрипт обрабатывает только **цветные** цвета (с насыщенностью > 15%)
3. Серые цвета (фон, границы, текст) остаются без изменений
4. Изменяется только параметр **saturation** в HSL-модели цвета
5. Результат сохраняется в `themes/Danast-Night.json`

### После запуска

1. Перезагрузите окно VS Code: **Ctrl+Shift+P** → **Reload Window** (или **Ctrl+R**)
2. Тема автоматически обновится с новыми цветами

### Восстановление оригинала

Если вам не понравился результат:

1. Скопируйте `themes/Danast-Night.backup.json` в `themes/Danast-Night.json`
2. Или запустите: `python adjust_saturation.py 1.0`

## Примеры

### Пример 1: Немного приглушить яркие цвета
```bash
python adjust_saturation.py 0.8
```
Отлично подходит для длительной работы, снижает нагрузку на глаза.

### Пример 2: Максимально спокойная тема
```bash
python adjust_saturation.py 0.5
```
Минималистичная тема с едва заметными цветовыми акцентами.

### Пример 3: Точная настройка
```bash
python adjust_saturation.py 0.65
```
Экспериментируйте с значениями от 0.5 до 0.9 для поиска идеального баланса.

## Технические детали

Скрипт использует HSL (Hue, Saturation, Lightness) цветовую модель:
- **Hue** (оттенок) — не изменяется
- **Saturation** (насыщенность) — умножается на коэффициент
- **Lightness** (яркость) — не изменяется

Это позволяет сохранить общую цветовую схему темы, изменяя только интенсивность цветов.
