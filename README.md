# Danast Night Theme

**Danast Night Theme** — это цветовая тема для Visual Studio Code и Qt Creator, вручную подобранная автором репозитория. Тема оформлена в тёмных тонах, обеспечивая комфортную работу в ночное время и минимизируя нагрузку на глаза. В репозитории представлены файлы для установки темы в VS Code и Qt Creator.

## Содержимое репозитория
- `themes/Danast-Night.json` — основной файл темы для Visual Studio Code
- `themes/danast-night.xml` — файл темы для Qt Creator
- `package.json` — метаданные и настройки расширения VS Code
- `git-commands.txt` — вспомогательный файл с командами Git
- `README.md` — описание репозитория

## Установка темы для VS Code
1. Скопируйте содержимое файла `themes/Danast-Night.json` в пользовательские темы или установите расширение через VS Code Marketplace (если опубликовано).
2. Активируйте тему через меню настроек VS Code.

## Установка темы для Qt Creator
1. Откройте Qt Creator и перейдите в настройки оформления.
2. Импортируйте файл `themes/danast-night.xml`.
3. Выберите тему из списка доступных.
